# Tic-Tac-Toe Game (Python OOP)

## About
A two-player Tic-Tac-Toe game developed using Python
and Object-Oriented Programming as a programming
practice project.

## Interface
-Console-based interactive gameplay with coordinate-based
-Player input and a text-rendered 3x3 game board.

## Features
- Interactive 3x3 game board.
- Two-player turn management.
- Input validation to prevent invalid moves.
- Automatic win and draw detection.
- Replay functionality.
- Cumulative scoreboard to track match results.

## Technologies Used
- Python
- Object-Oriented Programming
- 2D Lists
- Dictionaries

## How to Run
1. Download the Python file.
2. Open it using a Python interpreter.
3. Run the program.
4. Follow the on-screen instructions to play.

## Learning Outcomes
- Practised implementing classes and methods.
- Understood object attributes and return values.
- Gained experience with dictionaries and nested lists.
- Practised conditional logic and input validation.
